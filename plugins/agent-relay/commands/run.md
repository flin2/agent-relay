Require an explicit backend from the user's request or `--backend opencode|codex|claude`; ask if it is missing. Use the matching thin launcher agent: `relay-opencode-sub` or `relay-opencode-api` for OpenCode, `relay-codex` for Codex, and `relay-claude` for Claude. OpenCode requires `--route sub|api`; `--zen` and `--go` apply only to the `sub` route. Claude takes an optional `--route sub|api`: without it the launcher picks `sub` when a Claude subscription login is detected, otherwise `api` when `ANTHROPIC_API_KEY` is set, and fails before launch otherwise; the handoff marks an automatic choice `(default)`. `--zen` and `--go` are rejected for Claude. Do not pass route or gateway options to Codex.

Forward the user's task text, directory, permission choice, model, effort, and any stated verification requirement verbatim. Add no analysis and do not inspect the target repository. The launcher makes one detached `run --backend ...` call with task text on stdin, using a single-quoted heredoc. Codex read-only is enforced by its sandbox (`--sandbox read-only`); OpenCode read-only selects the `plan` agent, which avoids edit tools but permits shell writes unless OpenCode permissions deny them. Configure OpenCode to deny shell for the plan agent when enforcement is required. Claude read-only runs with `--safe-mode --restricted --strict-mcp-config`: tools are limited to Read, Grep, and Glob, plus Bash restricted to a prefix-matched allow list of read-only Git commands with deny rules for file-writing and external-program options, and anything that would prompt is denied. User plugins, hooks, skills, MCP servers, user settings, and repository `CLAUDE.md` are not loaded in read-only jobs, which load only Claude Code's built-in plugins; this is application-level enforcement inside Claude Code, not an OS sandbox, and live checks covered only the write attempts listed in the plugin guide. Add `--write` only when the user authorizes edits. For Claude, `--write` selects `acceptEdits`, loads the user's full Claude configuration, and denies shell commands not already allowed by the user's settings rather than prompting. Claude `--model` is passed verbatim, and `--effort` must be `low`, `medium`, `high`, `xhigh`, or `max`.

For a detached launch, read the handoff and start its exact `wait` command through Bash with `run_in_background: true` and no timeout from this originating conversation. Keep the returned Bash session associated with this conversation; when it exits, read the exact `result` command and present the captured result. If the waiter is absent after a session restart, use the printed manual `wait`, `result`, and `cancel` commands with the printed state root. For an explicit inline request, pass `--wait`, keep the stderr handoff for recovery if collection is interrupted, and return the captured stdout response.
